# Changelog

## 0.1.0-preview - 2026-10-21

- Prepared the customer and operations frontend code for an open-source community snapshot.
- Replaced embedded production Supabase configuration with an explicit, local example.
- Excluded production configuration files, brand artwork and customer assets.
- Added GNU AGPL-3.0 licensing, security and contribution guidance.
- Added a standalone mock demo with fictional work orders, customers and budgets.
- Added repository checks and GitHub Actions syntax validation.

**Known gaps:** no independent backend, schema migrations, Edge Functions, complete RLS suite or live production support. This preview is not a complete runnable SaaS product.
