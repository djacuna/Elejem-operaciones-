# Contributing

ELEJEM Operations is at the initial source-release stage. Contributions are welcome when the repository has its base code and backend published.

Open a GitHub Issue before major changes. Keep PRs scoped and explain reproduction steps, expected behavior and tests. Do not upload secrets, production tenant identifiers, customer details or real photos to Issues, commits or screenshots. Changes must preserve the OSS edition's rule that no browser environment silently connects to ELEJEM production.

Do not assume the frontend export is a complete application. All contributions are reviewed manually.
